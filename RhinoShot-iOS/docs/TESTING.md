# تست iOS — چک‌لیست

## ۱. پیش‌نیاز

* iPhone با iOS 16 یا بالاتر، نور روز یا نور یکنواخت اتاق، پس‌زمینه‌ی ساده.
* برای مقایسه: همان ۹ نما را با نسخه‌ی اندروید بگیرید.

## ۲. تست کالیبراسیون (هر گوشی یک‌بار)

| # | گام | انتظار |
|---|-----|--------|
| ۱ | صفحه‌ی عکاسی → «کالیبراسیون» | دیالوگ سه‌مرحله‌ای باز شود |
| ۲ | بیمار مستقیم به دوربین → «ثبت زاویه‌ی صفر» | عدد yaw/pitch روی ۰ بایستد |
| ۳ | بیمار سر را به **راست خودش** بچرخاند (‎>۱۸°) → «ثبت جهت راست» | yaw مثبت شود (‎+۴۵) |
| ۴ | بیمار چانه را **بالا** ببرد (‎>۱۲°) → «ثبت جهت بالا» | pitch مثبت شود (‎+۳۰) |
| ۵ | «ذخیره» → اپ را ببندید و باز کنید | مقادیر باقی بمانند |

## ۳. تست ۹ نما

| # | نما | شرط پذیرش |
|---|-----|-----------|
| ۱ | روبروی کامل | yaw ≈ ۰، pitch ≈ ۰، فاصله‌ی متوسط، شاتر خودکار |
| ۲ | روبروی خندان | همان + «لبخند ثبت شد» |
| ۳ | نیم‌رخ راست | yaw ≈ ‎+۷۵ (±۱۲) |
| ۴ | نیم‌رخ چپ | yaw ≈ ‎−۷۵ (±۱۲) |
| ۵ | سه‌رخ راست | yaw ≈ ‎+۴۵ (±۹) |
| ۶ | سه‌رخ چپ | yaw ≈ ‎−۴۵ (±۹) |
| ۷ | سر بالا | pitch ≈ ‎+۳۰ (±۹) |
| ۸ | سر پایین | pitch ≈ ‎−۳۰ (±۹) |
| ۹ | کلوزآپ بینی | ثبت **دستی**، بینی در مرکز، صورت پر کادر |

در هر نما باید پیام‌های راهنما به فارسی و به‌درستی تغییر کنند:
«سر را به سمت راست بچرخانید (۲۳° مانده)»، «کمی نزدیک‌تر شوید»،
«نور محیط کم است؛ روشن‌تر کنید»، «تصویر تار است؛ گوشی را ثابت نگه دارید».

## ۴. تست دروازه‌های کیفیت

| شرایط | انتظار |
|-------|--------|
| چراغ خاموش | پیام نور کم + عدم شاتر خودکار |
| فلاش مستقیم | پیام نور زیاد |
| تکان‌دادن گوشی | پیام تاری |
| دور شدن زیاد | پیام «کمی نزدیک‌تر شوید» |
| خارج‌کردن چهره از کادر | پیام «چهره دیده نمی‌شود» |
| چشم‌های بسته | پیام هشدار (غیرمسدودکننده) |
| حالت «آسان» | تلرانس بازتر، شاتر راحت‌تر |

## ۵. تست ذخیره و خروجی

| مورد | انتظار |
|------|--------|
| پوشه‌ی جلسه | ۹ فایل `NN_<label>.jpg` + `session.json` + `consent.txt` |
| `session.json` | ۹ رکورد با yaw/pitch/smile/brightness/sharpness |
| EXIF | `Exif.UserComment` و `ImageDescription` درست باشد |
| برگه‌ی تماس | یک تصویر ۳×۳ با عنوان فارسی |
| نسخه‌ی چاپی | تعداد فایل = تعداد عکس‌ها، ابعاد 1181×1772 یا 1535×2126 |
| انتقال به گالری | مجوز خواسته شود و فایل‌ها ظاهر شوند |
| اشتراک‌گذاری | پنل AirDrop/Message باز شود |
| «حذف کامل» | کل پوشه‌ی جلسه از دستگاه پاک شود |

## ۶. تست حریم خصوصی

* با Airplane Mode کل چرخه انجام شود (اپ نباید خطا بدهد).
* `Settings ▸ General ▸ iCloud` — پوشه‌ی RhinoShot نباید در iCloud باشد.
* حذف یک جلسه از صفحه‌ی خانه → فایل‌ها دیگر در «Files» دیده نشوند.
* پس از حذف، `session.json` در هیچ مسیری باقی نمانده باشد.

## ۷. تست پایداری

* ۱۰ دقیقه عکاسی پیاپی → نشت حافظه یا داغ‌شدن گوشی دیده نشود.
* تعویض دوربین جلو/عقب در حین عکاسی → کرش نکند.
* بستن اجباری اپ وسط عکاسی → در بازبینی، جلسه‌ی نیمه‌کاره دیده شود.
* چرخش گوشی (اپ در حالت portrait قفل است) → چیدمان به‌هم نریزد.

## ۸. سازگاری با اندروید

یک بیمار را با هر دو نسخه عکاسی کنید و مقایسه کنید:

* شماره و ترتیب فایل‌ها یکسان باشد.
* `session.json` در هر دو قابل خواندن باشد (ساختار یکسان).
* زاویه‌های ثبت‌شده در بازه‌ی ۲ درجه‌ی اختلاف باشند (اختلاف ذاتی مدل/نورپردازی).
* کیفیت چاپ یکسان باشد.
